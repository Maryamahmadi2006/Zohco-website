# Zohco Website

A responsive website recreated from an existing Framer design as part of a front-end development assignment.

## About the Project

Zohco is an eco-focused website concept designed around sustainable solutions, technology, and environmental responsibility.

For this project, I was provided with an existing website design created in Framer. My task was to recreate the website through front-end development and turn the visual design into a functional, responsive website using code.

The original visual design was created by another designer. I did not create the original design; my role was to code, rebuild, and implement the provided design.

## My Role

My main responsibility was the front-end development and recreation of the provided design.

I worked on:

- Recreating the website layout
- Writing and organizing HTML
- Styling the website with CSS
- Adding JavaScript interactions
- Making the website responsive
- Recreating different sections and components
- Adding images and background videos
- Creating navigation and mobile menu interactions
- Implementing animations and transitions
- Fixing layout and responsiveness issues
- Connecting the different pages together
